# ES6 Data Manipulation

This project covers JavaScript ES6 data manipulation using arrays, sets, maps, typed arrays, and higher-order functions.

## Tasks

### 0. Basic list of objects

Create a list of students containing their ID, first name, and location.

### 1. More mapping

Extract student IDs from a list of students using `map`.

### 2. Filter

Filter students by their location using `filter`.

### 3. Reduce

Calculate the sum of all student IDs using `reduce`.

### 4. Combine

Filter students by city and add their grades using `filter` and `map`.

### 5. Typed Arrays

Create an `ArrayBuffer` and use a `DataView` to set an `Int8` value at a specific position.

### 6. Set data structure

Create a `Set` from an array.

### 7. More set data structure

Check whether all values in an array exist in a `Set`.

### 8. Clean set

Return the parts of `Set` values that start with a specified string.

### 9. Map data structure

Create a `Map` containing grocery items and their quantities.

### 10. More map data structure

Update grocery quantities from `1` to `100`.

## Requirements

* Ubuntu 20.04 LTS
* Node.js 20.x.x
* npm
* JavaScript files using the `.js` extension
* Jest for testing
* ESLint for linting
