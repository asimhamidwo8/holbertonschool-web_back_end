# NoSQL

This project contains exercises using MongoDB and PyMongo.

## Tasks

### 0. List all databases

Lists all MongoDB databases.

### 1. Use or create a database

Uses or creates the `my_db` database.

### 2. Insert a document

Inserts a document into the `school` collection.

### 3. All

Lists all documents in the `school` collection.

### 4. Match

Lists documents where the name matches `Holberton school`.

### 5. Count

Counts the number of documents in the `school` collection.

### 6. Update

Adds the address `972 Mission street` to Holberton school documents.

### 7. Delete

Deletes all Holberton school documents.

### 8. All Python

Returns all documents from a MongoDB collection using PyMongo.

### 9. Insert a school

Inserts a school document into a MongoDB collection and returns its `_id`.

### 10. Update topics

Updates the topics of a school based on its name.

### 11. Schools by topic

Returns all schools that have a specific topic.

### 12. Log stats

Provides statistics about Nginx logs stored in MongoDB.

The script displays:

* The total number of logs.
* The number of requests for each HTTP method: `GET`, `POST`, `PUT`, `PATCH`, and `DELETE`.
* The number of `GET` requests to `/status`.

The MongoDB database is `logs` and the collection is `nginx`.

## Requirements

* Python 3
* MongoDB
* PyMongo
