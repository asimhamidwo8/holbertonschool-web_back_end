# Python Variable Annotations

This project introduces Python type annotations and demonstrates how to annotate variables, function parameters, return values, and complex types.

## Tasks

### 0. Basic annotations - add
A function that adds two floats and returns a float.

### 1. Basic annotations - concat
A function that concatenates two strings and returns a string.

### 2. Basic annotations - floor
A function that takes a float and returns its floor as an integer.

### 3. Basic annotations - to_str
A function that converts a float to a string.

### 4. Define and annotate variables
Defines variables with explicit types:
- int
- float
- bool
- str

### 5. Complex types - list of floats
A function that takes a list of floats and returns their sum.

### 6. Complex types - mixed list
A function that takes a list containing integers and floats and returns their sum as a float.

### 7. Complex types - tuple
A function that takes a string and an integer or float and returns a tuple containing the string and the square of the number.

### 8. Complex types - functions
A function that returns another function using `Callable`.

### 9. Complex types - element length
A function that takes an iterable of sequences and returns a list of tuples containing each sequence and its length.
