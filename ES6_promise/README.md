# ES6 Promises

This project introduces JavaScript Promises and asynchronous programming using ES6.

## Learning Objectives

By the end of this project, you should be able to:

* Understand and use JavaScript Promises.
* Create resolved and rejected Promises.
* Handle Promise results with `then`, `catch`, and `finally`.
* Resolve multiple Promises using `Promise.all`.
* Wait for multiple Promises to settle using `Promise.allSettled`.
* Return the first resolved Promise using `Promise.race`.
* Throw and handle errors using `throw`, `try`, `catch`, and `finally`.

## Concepts Covered

### Promise.resolve

Creates a Promise that is immediately fulfilled.

### Promise.reject

Creates a Promise that is immediately rejected with an error.

### Promise.all

Waits for all Promises to fulfill.

### Promise.allSettled

Waits until all Promises have settled, whether fulfilled or rejected.

### Promise.race

Returns the result of the first Promise to settle.
