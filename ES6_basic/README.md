# ES6 Basic

This project introduces the main features of ECMAScript 2015 (ES6) in JavaScript.

## Learning Objectives

By completing this project, I learned how to use:

* `const` and `let`
* Block scope
* Arrow functions
* Default parameters
* Rest parameters
* Spread syntax
* Template literals
* Object property shorthand
* Computed property names
* ES6 method properties
* `for...of` loops
* Object creation and iteration

## Requirements

* Ubuntu 20.04 LTS
* Node.js 20.x.x
* npm 9.x.x or later
* Jest
* ESLint
* Babel

## Installation

Install the project dependencies:
